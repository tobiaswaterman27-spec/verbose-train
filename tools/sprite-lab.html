Sprite Lab

All ten starter first forms, generated entirely from code — no image files. Each is its own model: shared anatomy conventions and one rig, but no shared template. Pick one to inspect its four directions, five animations, proportion check and frame sheet.

One model, four views

Each creature is defined once as parts in 3D space — pos[x,y,z], size, pivot. The four directions are projections of that one model, so proportions can't drift.

Rotation, projected per view

A pitch about the hip is an in-plane rotation from the side but foreshortening from the front. The renderer resolves that per view, and keeps the light in world space so shading stays consistent.

Every creature runs differently

Sprint is authored per species. Cindercrow pitches forward and holds its wings out; Sporelet drops into a four-legged bound. Same engine, different character.

Verified, not asserted

The generator measures each view's real pixel bounds and reports whether crown, ground and height agree — so drift shows up as a number, not something to catch by eye.

The ten elements

Wildhollow's type system. Relationships are deliberately asymmetric — Verdant is the most exposed element on defense and Umbra the least, which is what gives team-building its shape.

The ten starters — first form
Frames rendered at 80×72 px by a hand-written rasterizer — no anti-aliasing, hue-shifted three-step shading ramps, rotated-ellipse rasterization and a one-pixel outline pass. Creature designs, names, elements and palettes are original to this project.
