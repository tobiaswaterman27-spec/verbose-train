Sprite Lab

Two test creatures run through the procedural sprite generator. Every frame below is drawn from code — no image files. The question this page exists to answer: do the four directions stay on-model?

One model, four views

Each creature is defined once as body parts in 3D space — pos[x,y,z] and size. Front, back, left and right are projections of that single model, so proportions can't drift between them.

Animation in model space

A walk cycle swings legs along the creature's own forward axis. Because the motion is defined before projection, all four directions inherit a correct cycle for free.

Verified, not asserted

The generator measures each rendered view's pixel bounds and compares them. The proportion table below reports real numbers, so a drift shows up as a failure rather than something you have to spot by eye.

Rendered at 44×40 px per frame with a hand-written rasterizer — no anti-aliasing, hue-shifted three-step shading ramps, and a one-pixel outline pass. Creature designs, names and palettes are original to this project.
